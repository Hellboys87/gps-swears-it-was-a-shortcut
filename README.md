The GPS's one-line excuse for sending the driver down the wrong road, written for make.fun's "The GPS Swears It Was a Shortcut" bounty. The GPS cut through a wedding because the map promised it cake — smug, defensive, and blaming the map, with the cake worth more than the driver's missed exit.

## Run it

```sh
node main.ts
```

Writes the excuse (109 characters, one line) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
